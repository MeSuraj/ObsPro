## 🚀 Getting Started (Local Setup)

If you want to run this project locally on your machine, follow these simple steps:

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MeSuraj/ObsPro.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd ObsPro
   ```

3. **Open the project:**
   Simply open the `index.html` file in your favorite browser, or if you are using Node/React, run:
   ```bash
   npm install
   npm start
   ```
